## 🎯 هدف پروژه
مقایسه حقوق متخصصان حوزه در ۵ کشور مختلف به منظور: شناسایی پردرآمدترین بازارهای کار تحلیل تأثیر عوامل اقتصادی بر حقوق ارائه راهنمای شغلی برای مهاجران دیجیتال

---

## 📊 روش‌شناسی
### جمع‌آوری داده‌ها
- منابع: Glassdoor, PayScale, LinkedIn (آخرین بروزرسانی: تیر ۱۴۰۲)
- کشورها: ایران، آمریکا، آلمان، هند، ژاپن
- حرفه‌ها: 
  - توسعه‌دهنده نرم‌افزار
  - مهندس امنیت سایبری
  - تحلیلگر داده

### ابزارها
- Python 3.11
- کتابخانه‌ها: Pandas, Matplotlib, BeautifulSoup
- [کد پروژه در GitHub](https://github.com/thecodingparsa/global-tech-salaries)
