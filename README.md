📌 معرفی پروژه

این پروژه شامل دو بخش اصلی است:

    تولید داده‌های نمونه حقوق برای مشاغل مختلف در کشورهای مختلف

    تحلیل و مصورسازی داده‌های تولید شده

🛠 نیازمندی‌ها

    Python 3.8+

    کتابخانه‌های مورد نیاز:
    text

    pandas
    numpy
    matplotlib

🚀 نحوه اجرا

    نصب کتابخانه‌ها:
    bash

pip install pandas numpy matplotlib

اجرای تولید داده:
bash

python scraper.py

اجرای تحلیل داده:
bash

    python analysis.py
